# Hero Banner Background Image

Silakan simpan gambar background untuk hero banner di folder ini dengan nama:
- `hero-banner.webp` (format WebP - disarankan untuk kualitas terbaik)
- `hero-banner.jpg` (format JPG)
- atau `hero-banner.png` (format PNG)

## Spesifikasi Gambar:
- **Format**: WebP (disarankan), JPG, atau PNG
- **Ukuran**: Disarankan minimal 1920x600px untuk tampilan optimal
- **Rasio**: 16:9 atau 3:1 untuk hasil terbaik
- **Ukuran file**: Disarankan maksimal 500KB untuk performa loading yang baik
- **Nama file**: `hero-banner.webp`, `hero-banner.jpg`, atau `hero-banner.png`

## Prioritas File:
1. `hero-banner.webp` (jika ada, akan digunakan terlebih dahulu)
2. `hero-banner.jpg` (jika webp tidak ada)
3. `hero-banner.png` (jika webp dan jpg tidak ada)

## Catatan:
- Gambar akan otomatis digunakan sebagai background hero banner
- Overlay gradient akan ditambahkan otomatis untuk memastikan teks tetap terbaca
- Background akan menggunakan `background-attachment: fixed` untuk efek parallax
- Jika tidak ada gambar, akan menggunakan gradient default

## Tips:
- Gunakan gambar dengan kontras tinggi untuk hasil terbaik
- Pastikan area tengah gambar tidak terlalu gelap atau terlalu terang
- Gambar akan di-crop secara otomatis untuk menyesuaikan ukuran layar
- Kompres gambar sebelum upload untuk performa yang lebih baik
