# Logo Files

Silakan simpan file logo Anda di folder ini dengan nama:
- `logo.png` (format PNG)
- atau `logo.svg` (format SVG)

## Spesifikasi Logo:
- **Format**: PNG atau SVG (disarankan SVG untuk kualitas lebih baik)
- **Ukuran**: Disarankan tinggi maksimal 45px, lebar proporsional
- **Background**: Transparan (untuk PNG)
- **Nama file**: `logo.png` atau `logo.svg`

## Cara Menggunakan:
1. Simpan file logo Anda di folder `assets/img/logo/`
2. Beri nama file sebagai `logo.png` atau `logo.svg`
3. Logo akan otomatis muncul di header website
4. Jika logo tidak ditemukan, akan muncul teks "🌴 Sawit Digital" sebagai fallback

## Catatan:
- Jika kedua file (logo.png dan logo.svg) ada, sistem akan menggunakan logo.png terlebih dahulu
- Pastikan file logo memiliki background transparan untuk hasil terbaik
- Ukuran logo akan otomatis disesuaikan dengan tinggi 45px
